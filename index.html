04 / Methods

What was measured

Full arrays, one CPU thread, native compressor APIs, and independent pointwise error verification.

Error bound

Range-relative tolerance

ε = α × (max(x) − min(x))

Each field is tested from 1E-1 through 1E-6. The verifier checks the reconstructed values against the original bound. Two all-zero CESM fields are excluded from this protocol.

Timing

API wall time

Compression and decompression timers include configuration and allocation. Input I/O, startup, input copies and validation are outside the timer. Throughput is reported in MiB/s, where 1 MiB = 1,048,576 bytes.

Aggregation

Bytes and elapsed time

Dataset ratio uses total input and compressed bytes. Throughput uses total input bytes and the sum of mean field times. RD uses element-weighted RMS normalized error. Miranda uses its original float64 arrays.

Data policies, figure settings & backend versions

Quality curves. SSIM, PCC, spectral and spatial correlation use 1E-1 to 1E-5 and median field quality against the combined bit rate. SSIM and Pearson r use their original scores. Use Full rate range to see all measurements when the main chart shortens a high-rate plateau. Cross-variable plots use the combined rate of the participating fields. Verify physical co-location before interpreting them. Error autocorrelation is a diagnostic, not a universal error ranking.

Figure settings. RD curves show 1E-1 to 1E-5. Throughput plots show 1E-2 to 1E-5. The Pareto frontier uses only 1E-3 and compares both compression and decompression throughput with compression ratio. The full set of bounds is available in the CSV files.

Compressor tolerances. SPERR float32 uses a tighter tolerance to accommodate reconstruction rounding; one SZ3 configuration was retried with a slightly smaller tolerance. The verifier checks the nominal bound. Effective bounds and the adjustment are recorded in the downloads.
